Live Call CRM Dashboard Architecture

System Architecture (MVP)

End-to-end request flow (one customer sentence)

  1. Customer speaks → STT in browser converts speech to text.
  2. Browser sends POST /api/calls/:id/message with the text.
  3. RAG: question → embedding → cosine similarity → top-3 knowledge chunks.
  4. Orchestrator builds the system prompt (rules + today's date + language + chunks) and sends the full conversation history (memory) to Gemini.
  5. Gemini either answers, or returns a function call (e.g. save_lead_info, book_appointment).
  6. Our code runs the tool → writes to the CRM → returns the result → Gemini writes the final reply.
  7. Reply + updated lead + actions go back to the browser → TTS speaks it → mic reopens.
  8. On End Call: transcript → Gemini (structured JSON) → summary, sentiment, objections → saved → dashboard.
